Metodología de trabajo

El desarrollo de cada propuesta se organiza en etapas para mantener una estructura clara y facilitar las revisiones.

1. Organización

Antes de comenzar el desarrollo, organizo el contenido y determino la estructura necesaria para el sitio web.

2. Desarrollo

Construyo la estructura del sitio y aplico los estilos utilizando las herramientas apropiadas para cada proyecto.

3. Adaptación responsive

Reviso el comportamiento del sitio en diferentes tamaños de pantalla para asegurar su correcta visualización.
