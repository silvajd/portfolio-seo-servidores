Mis Proyectos

En esta sección se encuentran algunos de los proyectos realizados durante mi proceso de aprendizaje en desarrollo web.

Cada proyecto representa una etapa diferente de aprendizaje, desde HTML hasta la incorporación de SCSS, layouts responsivos y animaciones.

Proyectos realizados

Estos proyectos muestran la evolución del sitio a medida que incorporé diferentes tecnologías.

Proyecto HTML

Primera versión del sitio realizada con HTML5, etiquetas semánticas y navegación entre páginas.

Proyecto CSS

Incorporación de colores, tipografías, fondos y estilos personalizados.

Proyecto Flexbox

Incorporación de Box Model y Flexbox para construir layouts flexibles y adaptables.

Proyecto SCSS

Migración de CSS a SCSS mediante variables, mixins, nesting, extend y partials.

Herramientas utilizadas

A lo largo de estos proyectos fui incorporando diferentes herramientas para construir sitios web cada vez más completos.

HTML5 y CSS3

HTML organiza semánticamente el contenido y CSS define la presentación visual.

Flexbox y CSS Grid

Permiten crear layouts flexibles y estructuras bidimensionales adaptables.

SCSS y Bootstrap

SCSS mejora la organización del código y Bootstrap proporciona componentes reutilizables y responsivos.
